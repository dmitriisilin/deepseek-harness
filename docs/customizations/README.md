# Кастомизации AI Control

Рабочий реестр частного форка `di735` поверх DSH 0.2.2-rc.5. Перед ребейзом сравни целевой релиз DSH с критериями каждого билета. Если апстрим покрывает сценарий, проверь его на тестовой версии и убери соответствующий патч. Если покрывает часть, перенеси оставшуюся часть и обнови ссылки, статус и проверки.

| Билет | Область | Статус |
|---|---|---|
| [AI-01](AI-01-interface.md) | Интерфейс и значки PWA | Красная сборка проверена, зелёное оформление сведено в общий вариант сборки |
| [AI-02](AI-02-login.md) | Вход, привязка устройств и безопасность | Работает в основном контуре, усиление регистрации обсуждается |
| [AI-03](AI-03-local-speech.md) | Распознавание речи | Deepgram во всех веб-профилях |
| [AI-04](AI-04-voice-messages.md) | Голосовые сообщения | Потоковая загрузка проверена в Chrome и на телефоне Димы, новая индикация проверена в Chrome |
| [AI-05](AI-05-plugin-composition.md) | Плагины и профили | Голосовой стек выделен, состав тестового профиля предстоит проверить |
| [AI-07](AI-07-adaptive-supervisor.md) | Управляющий агентным циклом и диагностика | TODO. Supervisor выключен, результаты экспериментов зафиксированы |
| [AI-08](AI-08-auto-review-default.md) | Auto review для новых чатов | Проверен старт нового чата с политикой ask |
| [AI-09](AI-09-personal-memory.md) | Личная память Honcho и Hindsight | Работает на красном и зелёном, банки раздельны |
| [AI-06](AI-06-session-list.md) | Список сессий, пространства и быстрые диалоги | Список и создание сессий проверены в Chrome |

[План реализации интерфейса AI Control](AI-Control-implementation.md) содержит сценарии и критерии приёмки. [Подготовка выпуска](AI-Control-release.md) описывает отличия контуров и порядок перехода на зелёный.

В новом билете укажи исходный сценарий, владельца кода, зависимость от апстрима, критерий замены и проверку перед выпуском. Узкие пункты одного сценария можно хранить в одном билете.
