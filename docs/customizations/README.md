# Кастомизации AI Center

Рабочий реестр частного форка `di735` поверх DSH 0.2.2-rc.5. Перед ребейзом сравни целевой релиз DSH с критериями каждого билета. Если апстрим покрывает сценарий, проверь его на тестовой версии и убери соответствующий патч. Если покрывает часть, перенеси оставшуюся часть и обнови ссылки, статус и проверки.

| Билет | Область | Статус |
|---|---|---|
| [AI-01](AI-01-interface.md) | Интерфейс и значки PWA | Красная сборка и Chrome-приёмка готовы, Android впереди |
| [AI-02](AI-02-login.md) | Вход, привязка устройств и безопасность | Работает в основном контуре, усиление регистрации обсуждается |
| [AI-03](AI-03-local-speech.md) | Локальное распознавание речи | Работает в основном контуре |
| [AI-04](AI-04-voice-messages.md) | Голосовые сообщения | Проверено в Chrome с тестовым провайдером, мобильная приёмка впереди |
| [AI-05](AI-05-plugin-composition.md) | Плагины и профили | Голосовой стек выделен, состав тестового профиля предстоит проверить |
| [AI-06](AI-06-session-list.md) | Список сессий, пространства и быстрые диалоги | Список и создание сессий проверены в Chrome |

[План реализации интерфейса AI Control](AI-Control-implementation.md) содержит порядок работ, сценарии и критерии приёмки.

В новом билете укажи исходный сценарий, владельца кода, зависимость от апстрима, критерий замены и проверку перед выпуском. Узкие пункты одного сценария можно хранить в одном билете.
