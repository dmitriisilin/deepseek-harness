# AI-02. Вход и безопасность

**Задумка.** Знакомые адреса доступны семье с зарегистрированных устройств. Знание адреса не даёт доступ. Для защиты при утечке действующей регистрационной ссылки предлагается отдельное подтверждение новой привязки на ноутбуке.

**Владельцы.** В репозитории `vpn` код `dsh/bin/front.mjs`, `dsh/bin/dsh-enroll` и схема в `dsh/README.md`. Cloudflare и резервный RU-туннель ведут к одному `dsh-front`. Привязка сделана по cookie браузера. Хост DSH слушает loopback и выдаёт собственную сессию.

**Перед ребейзом.** Проверить штатные возможности идентификации, отзыва устройств и запуска PWA, а также контракт входа DSH: где объявляется токен, какой ответ завершает обмен и какие атрибуты у cookie. Проверить, можно ли убрать прокси-обход цикла переадресаций после изменений апстрима.

**Приёмка.** Чистый браузер получает отказ по обычному адресу. Зарегистрированный Chrome и установленная PWA входят через оба адреса, включая запуск после перезапуска DSH. Отозванный профиль теряет доступ.
