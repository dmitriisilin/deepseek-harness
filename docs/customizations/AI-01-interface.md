# AI-01. Интерфейс и PWA

**Задумка.** Семейная точка входа AI Control. Основная PWA зелёная, экспериментальная красная. Мобильный чат отдаёт приоритет тексту и основным действиям. У AI Control свой визуальный стиль.

## Мобильный чат

- Увеличить шрифт сообщений, поля ввода и заголовка, а также иконки и области нажатия. Микрофон должен быть заметен. На узком экране текст чата 17 px с интервалом около 25 px, иконки 22–24 px, зоны нажатия 44 px. В открытом чате поле ввода компактное и растёт по мере набора.
- Оставить одну верхнюю строку. Перенести «Траекторию» в меню ⋯ текущего чата и убрать постоянную строку вкладок. Сохранить возможность вернуться из траектории в чат.
- Убрать лайк и дизлайк из действий под ответом. Убрать постоянно видимую строку действий; вариант для примерки — «Копировать» и прочие полезные действия в меню сообщения.
- В меню «+» показывать «Камера», «Фото» и «Файлы». Команды остаются доступны через `/`. Все три источника проходят через обычный механизм вложений.
- В композере показывать название модели с вертикальным троеточием в серой кнопке. Для «+» и микрофона использовать такой же фон. В меню модели показывать три однотипные строки «Модель», «Усилие» и «Доступ» с текущими значениями справа. На телефоне меню занимает доступную ширину с отступами по 12 px. «Доступ» раскрывает существующие режимы и сохраняет их подтверждения.
- Ход работы показывать одной свёрнутой строкой с индикатором. Подробности раскрываются по нажатию. Показывать саму расшифровку голосового сообщения без технического заголовка.
- Для установленной красной PWA использовать белый значок с янтарно-малиновым контуром. В приложении показывать контур на прозрачном фоне.
- Показывать примерную стоимость всей сессии в USD. Суммировать запросы по фактически использованным моделям и четырём категориям токенов. Тарифы DeepSeek брать по пиковому прайсу, Claude по базовому прайсу с записью кэша на 5 минут. Для GPT-6.2 Sol брать Standard с учётом порога 272 тысяч входных токенов и записи кэша на 30 минут. Для остальных моделей использовать каталог pi-ai. Запросы без известного тарифа показывать отдельно в деталях. Оценка по текущим базовым тарифам не включает скидки, платные инструменты и налоги.
- Сохранить компактную строку статистики под композером. Показывать процент контекста и скорость генерации при наличии данных. Использовать существующие метрики DSH. Нижняя навигация по чатам, проектам, коду и артефактам для этого экрана не нужна.

## Где менять

- `apps/web` владеет манифестом и установочными значками. Исходники в [branding](../../apps/web/branding).
- `ui-conversation` владеет композером, меню представлений и индикатором контекста. `ui-trajectory` регистрирует представление «Траектория».
- `ui-chat` владеет типографикой, строкой действий сообщения и компактными метриками. Плагины могут добавлять действия в слот `conversation.chat.assistant-actions`.
- `ui-model-selection` уже выбирает модель и глубину рассуждений. `ui-permission-presets` отдельно выбирает режим разрешений. `voice-client` владеет микрофоном и записью.

## Перед ребейзом

Проверить штатные настройки брендинга, размера шрифта и мобильной плотности, а также слоты композера и чата. Если новая версия покрывает требование через тему или плагин, убрать соответствующий патч ядра.

## Приёмка

Проверить имя, значок и запуск обеих установочных точек. На узком экране Android Chrome проверить читаемость, открытие траектории и возврат в чат, копирование, вложения, запись и отправку, модель и режим разрешений. Статистика остаётся доступной мелкой строкой и не перекрывает поле ввода при открытой клавиатуре.

## GPT-6.2 Sol и Claude Opus 5.5 на staging

[Патч провайдеров](providers-staging.patch.yml) настраивает OpenAI Responses API и Anthropic Messages API. Добавить его в патч профиля `web` каждой красной службы. Обе службы читают `AI_CONTROL_OPENAI_API_KEY` и `AI_CONTROL_ANTHROPIC_API_KEY` из своих локальных файлов окружения. При исчерпании кредитов OpenAI в чате виден оригинальный текст ошибки провайдера. Для теста использовать пустой чат и короткое сообщение.
