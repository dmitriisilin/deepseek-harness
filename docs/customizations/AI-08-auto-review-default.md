# AI-08. Auto review для новых чатов

**Сценарий.** Новый чат Димы или Кати сразу получает штатный режим Auto review. Для каждого одобренного действия действует стандартный доступ этого режима. Отклонённый вызов по-прежнему требует подтверждения пользователя.

**Владелец.** `packages/interaction/permission-presets` применяет `AI_CONTROL_DEFAULT_AUTO_REVIEW=1` при создании сессии. Профиль должен загрузить `dsh-experimental-auto-review`. При отсутствии плагина действует обычное значение профиля. Уже сохранённые настройки доступа восстанавливаются из журнала сессии.

**Перед ребейзом.** Сверить, появилась ли в DSH поддержка операторского значения Auto review для новых сессий. Патч можно убрать, когда штатная настройка сохраняет политику `ask`, проверяет наличие плагина и работает после перезапуска.

**Приёмка.** Создать отдельный чат и чат внутри проекта. Проверить сохранённые события `permission/preset=auto` и `approval/policy=ask`. После перезапуска открыть старый диалог с другим режимом и убедиться, что его сохранённый выбор восстановился.
